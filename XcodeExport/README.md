# Try FlexDeck in Xcode

1. Open `FlexDeck.xcodeproj`.
2. Select the `FlexDeck` scheme and choose an iOS device destination.
3. For a physical iPhone, choose your Apple development team under **Signing & Capabilities** if Xcode asks.
4. Run the app, tap **Start tracking**, and allow camera access.

The iOS Simulator can build and display the app, but live hand tracking needs a physical iPhone camera.
